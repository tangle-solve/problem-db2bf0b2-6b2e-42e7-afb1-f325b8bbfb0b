### ALGO-000094: Single-exponential Directed Feedback Vertex Set
- **Subfield:** Parameterized algorithms, kernelization, and structural graph algorithms
- **Open:** Solve Directed Feedback Vertex Set parameterized by solution size \(k\) in \(2^{O(k)}n^{O(1)}\) time.
- **Status:** The classic FPT algorithm uses \(2^{O(k\log k)}\)-type dependence. Removing the logarithm in the exponent remains a standard target.
- **Type:** theory
- **Why:** Would improve exact cycle-breaking algorithms in directed networks.
- **Key works:** Chen, Liu, Lu, O’Sullivan, and Razgon (2008), *A Fixed-Parameter Algorithm for the Directed Feedback Vertex Set Problem*, DOI: 10.1145/1374376.1374404.
- **Related:** Systems biology—feedback-loop intervention.
